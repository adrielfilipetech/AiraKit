Usage Examples

Setup

3 core files

Every project that uses AiraKit — regardless of framework — must always load these three files, in this order:

tokens.css -> base.css -> main.js

index.html — <head> 

                            </head>
                            <link rel="stylesheet" href="/AiraKit/static/css/base/tokens.css">
                            <link rel="stylesheet" href="/AiraKit/static/css/base/base.css">
                            <script src="/AiraKit/static/js/main.js" defer></script>
                            </head>

Tokens.css: Color scheme, spacing, radii and typography for the whole kit and every component.

Base.css: Reset, base typography and the base HTML structure (content grid, flex utilities, spacing helpers). Depends on tokens.css.

Main.js: Defines and switches the theme (light/dark), and injects the <aira-navbar> / <aira-footer> web components.


Base html structure

navbar · main · footer

Every page follows the same 3-part skeleton inside the <body> tag: Navbar - Main - Footer

Each piece is independent — a page can drop the navbar, the footer, or both, and the layout still holds, since the <main> tag with .main-cont attribute always stretches to fill whatever space is left.

<aira-navbar>: Injected by main.js. Fixed at the top of the page, holds the logo, the theme toggle and the nav links.

<main class="main-cont">: Wraps the page's actual content. Grows to fill the remaining vertical space (flex: 1), pushing the footer to the bottom on short pages.

<aira-footer>: Injected by main.js. Sits at the bottom of the page with links and credits.

index.html — <body> 

                            <body>
                            <aira-navbar></aira-navbar>

                            <main class="main-cont">
                            <!-- page content -->
                            </main>

                            <aira-footer></aira-footer>
                            </body>

Using components

To use the basic components always include components.css file.

Also make sure to include components.js when using accordions, carrousel, checkboxes, toggle buttons or toast.js for the toasts.

index.html — components layer (optional) 

                            </head>
                            <link rel="stylesheet" href="/AiraKit/static/css/components/components.css">
                            <script src="/AiraKit/static/js/components.js" defer></script>
                            <script src="/AiraKit/static/js/toast.js" defer></script>
                            </head>

UI Icons

19 icons

Use icons with <img> from /static/icons/ui/. Icons automatically invert in dark mode. Do not use the .logo class or include logo in the filename, as either will prevent the icon from being inverted, unless it is intended. There are 19 icons available. See the full list on the Assets & Icons page.

example 
<img class="ui-icon" src="/AiraKit/static/icons/ui/download.svg" alt="download">

Accordion

2 variants

Single

A vertically stacked list of items where each one can be expanded or collapsed to reveal its content.

Opening one item automatically closes any other open item.

example 
<div class="accordion">
                                    <div class="accordion-item">
                                    <button class="accordion-trigger" aria-expanded="false">
                                    <span>What is AiraKit?</span>
                                    <svg class="accordion-icon" ...><polyline points="6 9 12 15 18 9"
                                    /></svg>
                                    </button>
                                    <div class="accordion-body">
                                    <div class="accordion-content">
                                    <p>A lightweight design kit — no build tools required.</p>
                                    </div>
                                    </div>
                                    </div>
                                    <!-- repeat .accordion-item for each entry -->
                                    </div>

Carousel

1 variant

Use the ids exactly as shown — carousel-demo and carousel-demo-dots — and leave the dots container empty; the dots are added automatically. Only one carousel per page is supported. Arrows and dragging/swiping work right out of the box. File components.js required.

01

Drag or use the arrows to navigate between slides.

02

Works with any content — images, cards, text.

03

Dots update automatically as you navigate.

example 
<div class="carousel" id="carousel-demo">
                            <div class="carousel-track">
                            <div class="carousel-slide"><div class="carousel-slide-inner">
                            <span class="carousel-slide-num">01</span>
                            <p>Slide content goes here.</p>
                            </div></div>
                            <!-- repeat .carousel-slide for each slide -->
                            </div>
                            <button class="carousel-btn carousel-btn--prev"
                            aria-label="Previous">...</button>
                            <button class="carousel-btn carousel-btn--next" aria-label="Next">...</button>
                            <!-- leave empty — components.js fills this with .carousel-dot buttons -->
                            <div class="carousel-dots" id="carousel-demo-dots"></div>
                            </div>

Toast

4 variants

Add the first div as shown below. It can be anywhere in the file (inside the </main> tag will do). Then add a button with the onClick method showToastKit(message, variant).

Important note: The `toast-kit` class is used for styling, while the `toast-kit` ID is used by `toast.js` to locate the div.

example 
<!-- once per page -->
                            <div class="toast-kit" id="toast-kit" role="status" aria-live="polite"></div>

                            <!-- anywhere in your JS -->
                            <button class="btn_out" onclick="showToastKit('Action completed!', 'success')">
                            Save
                            </button>

Toast variants (click to see the effects):

'default'
'success'
'error'
'warning'
